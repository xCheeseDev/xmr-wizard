Nodes

Fastest healthy first syncing nodes

The list ranks nodes fastest healthy first. Ping is the median of 3 probes from your browser to the node's RPC port (6s timeout each). Health comes from an hourly automated check of each node's block height — it can't be faked by a fast connection. Onion nodes only work in Tor Browser; in a normal browser they'll show as timeout.

How it works

  • Measured from you. Latency is probed from your own browser, because a node that's fast for someone else might be slow for you. Nothing is uploaded anywhere — the test traffic goes straight from your device to each node.
  • Speed + health. A fast ping alone doesn't prove a node is usable, so an hourly automated check records every node's block height and version into status.json. Nodes that are offline or far behind the chain are pushed to the bottom.
  • No backend. This page is static. The node list is a nodes.json file in the repo that anyone can improve with a pull request.
  • Honest limits. Browsers block normal requests to node RPC ports, so the probe uses a timing trick (see README). The health data is only as fresh as the last hourly check. A synced node you connect to still sees your IP — the privacy note below applies.

A privacy note

A remote node can see your IP address and when you broadcast transactions. If that bothers you, use one of the Tor onion nodes (in Tor Browser) — or better yet, run your own node. Your keys never touch this page either way.

Adding a node

Add your node here via Pull Request!

Pull requests welcome. Add an entry to nodes.json:

{
  "host": "node.example.com",
  "port": 18089,
  "network": "clearnet",
  "operator": "Your name / org",
  "region": "City, CC"
}
  • network: "clearnet", "onion", or "i2p"
  • port: 18089 is the standard restricted RPC port for public nodes
  • tls: set true only if the node serves RPC over HTTPS
  • operator: who runs it (optional but encouraged)
  • region: rough location, helps visitors pick nearby nodes (optional)
  • lat / lon: coordinates for the map, geocoded from region (optional; maintainers add them when a node is listed)

Please only list nodes you run or that are publicly advertised by their operator. The hourly check automatically flags entries that stop responding.
